# 塾 月末請求一覧表

Python（openpyxl）で作った、学習塾の月末請求一覧表の自動生成スクリプトです。

🔗 **サイトで見る**: https://ozakiray0619-000.github.io/juku-seikyu-ichiranhyo/

## ざっくり何ができるか

- ダミー生徒180人分（本校70 / 東校60 / 西校50）の請求データを自動生成して Excel ファイル（`一覧表.xlsx`）を出力
- 2枚のシート構成:
  - **月末請求一覧** — 生徒ごとの請求データ。Excelの「テーブル」機能を使っていて、行を増やしても数式・書式が自動でついてくる。このツールで人が入力する値（週コマ数、黄色いセル）はここにしかないので非表示にはしていない
  - **請求書** — No（生徒番号）か「No：生徒名」を選ぶと、その生徒だけの請求内容が自動で表示される。左側（A〜F列）がそのままPDFにできる正式な請求書、右側（H列以降）が入力用の操作パネル（単価表マスターもこの操作パネルの下に埋め込み）。さらにGmailの作成画面をワンクリックで開けるリンク付き（宛先・件名が入力済みの状態で開く。本文は本文プレビューからコピペ）
- 授業料・消費税・請求額はぜんぶExcelの数式で計算（手入力・手計算なし）。消費税は**授業料＋教材費**の合計に対して10%
- 対象年月・振込先・支払期日は請求書に記載（振込先はダミーの口座情報。実運用では書き換えてください）
- 請求書シートは生徒名ではなく一意な No で該当行を引くため、同姓同名の生徒がいても別人の請求内容が表示されることはない

## 使っているもの

- Python 3
- [openpyxl](https://openpyxl.readthedocs.io/)
- （PDF一括作成のみ）[pywin32](https://pypi.org/project/pywin32/) ＋ Windows + Microsoft Excel（インストール済みであること）

## 使い方

```bash
pip install openpyxl
python 一覧表.py
```

`一覧表.xlsx` が生成され、同時に `index.html` の埋め込みデータ（`const DATA = ...`）も
xlsxと同じ内容に自動で書き換えられます。**index.html のデータを手で書き換える必要は
ありません**（以前は手作業でコピペしており、xlsxとサイトの内容がずれるバグが実際に
起きたため、この同期は必ずスクリプト側で行う）。

### 請求書PDFの一括作成（任意・Windows専用）

```bash
pip install pywin32
python 請求書PDF一括作成.py
```

`一覧表.xlsx` の請求書シートを使って、生徒ごとに `請求書PDF/No_生徒名.pdf` を1人1ファイル
ずつ書き出します。裏でExcelを操作するため **Windows + Microsoft Excel が必須**です
（macOS/Linuxでは動きません）。180人分で `一覧表.xlsx` に書き込みは行わず
（`SaveChanges=False`）、実行前後で元のファイルは変更されません。
`win32.DispatchEx` で毎回新しいExcelプロセスを起動するため、実行中に他のExcelブックを
開いていても、それらを巻き込んで閉じることはありません（Windows + Excel実行環境で
180人分の生成・PDF出力・元ファイル無変更・他のExcelウィンドウが影響を受けないことを
確認済み）。

## 注意：GitHub上のファイルプレビューは使わない

GitHubのリポジトリ画面で `一覧表.xlsx` を直接クリックすると、GitHub組み込みの
プレビューが開きますが、**このプレビューからテキストをコピーすると文字化けする
ことがあります**（GitHub側のビューアの制限で、こちら側では直せません）。実際の
セルの中身（本文プレビューなど）はExcel COM経由で直接読み取って正常な日本語で
あることを確認済みです。

請求書の文章をコピーしたいときは、必ず次のどちらかを使ってください。

- GitHub Pagesのサイト（🔗 上記URL）から `一覧表.xlsx` をダウンロードし、
  実際のExcelで開いて「本文プレビュー」セルをコピーする
- `請求書PDF一括作成.py` で生成したPDFを開いて文章をコピーする

## 配布前チェック（重要）

`一覧表.xlsx` を配布・コミットする前に、必ず以下を確認してください。

1. **`python 一覧表.py` を実行し直したファイルを配布する**。Excelで開いて動作確認した
   あとのファイルをそのまま配布すると、請求書シートのNo入力欄（J4）にテスト用の値が
   残ったまま保存されてしまうことがある（実際に3回連続で発生した）。請求書シートが
   最初に開くシートなので、この値が残っていると開いた瞬間に特定の生徒の請求書が
   表示されてしまう。
2. **GitHub Pages の公開URLを実際に開いて、最新コミットの内容になっているか確認する**
   （`git log -1` のコミットハッシュと、サイトの見た目・配信ファイルの更新日時を突き合わせる）。
3. **配布している `一覧表.xlsx` を実際にダウンロードして開く**（生成スクリプトを読むだけでは、
   配布物本体に何が残っているかは分からない）。
4. **この README を読み返し、実際の挙動と食い違っていないか確認する**。

## ファイル

| ファイル | 内容 |
|---|---|
| `一覧表.py` | 生成スクリプト本体（`一覧表.xlsx` と `index.html` のデータを同時に生成） |
| `一覧表.xlsx` | 生成された Excel ファイル（サンプル） |
| `請求書PDF一括作成.py` | 請求書シートから生徒ごとのPDFを一括出力するスクリプト（Windows + Excel 専用） |
| `index.html` | GitHub Pages 用のプレビューページ |

※生徒名・メールアドレス・振込先などはすべてダミーデータです。
