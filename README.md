# 塾 月末請求一覧表

Python（openpyxl）で作った、学習塾の月末請求一覧表の自動生成スクリプトです。

🔗 **サイトで見る**: このリポジトリの GitHub Pages URL（下記参照）

## ざっくり何ができるか

- ダミー生徒180人分（本校70 / 東校60 / 西校50）の請求データを自動生成して Excel ファイル（`一覧表.xlsx`）を出力
- 3枚のシート構成:
  - **月末請求一覧** — 生徒ごとの請求データ。Excelの「テーブル」機能を使っていて、行を増やしても数式・書式が自動でついてくる
  - **単価表** — コースごとの単価・教材費のマスターデータ。ここを直すと、該当コースの生徒全員の請求額が自動で連動して変わる
  - **請求書** — No（生徒番号）か生徒名を入力すると、その生徒だけの請求内容が自動で表示される。さらにGmailの作成画面をワンクリックで開けるリンク付き（宛先・件名・本文が入力済みの状態で開く）
- 授業料・消費税・請求額はぜんぶExcelの数式で計算（手入力・手計算なし）

## 使っているもの

- Python 3
- [openpyxl](https://openpyxl.readthedocs.io/)

## 使い方

```bash
pip install openpyxl
python 一覧表.py
```

`一覧表.xlsx` が生成されます。

## ファイル

| ファイル | 内容 |
|---|---|
| `一覧表.py` | 生成スクリプト本体 |
| `一覧表.xlsx` | 生成された Excel ファイル（サンプル） |
| `index.html` | GitHub Pages 用のプレビューページ |

※生徒名・メールアドレスなどはすべてダミーデータです。
